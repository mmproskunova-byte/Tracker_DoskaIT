# Tracker_DoskaIT # FlowBoard

Канбан-трекер задач для небольшой IT-команды. Спокойный, чистый интерфейс без визуального шума: пять колонок, четыре роли, уведомления и подсветка горящих дедлайнов.

![Доска задач FlowBoard](docs/board.png)

## Возможности

- **Канбан-доска** из пяти колонок: Бэклог → В работе → На ревью → Тестирование → Готово
- **Перетаскивание карточек** drag & drop или кнопками в окне задачи — с проверкой прав на переход
- **Четыре роли** с разной видимостью и набором действий
- **Правила переходов**: движет только тот, кому это разрешено (назначение — только PM, ревью — только исполнитель и т.д.)
- **Возврат назад только с комментарием** — для багов обязательно описание
- **Уведомления**: колокол с непрочитанными, оповещение исполнителю при назначении
- **Подсветка дедлайна** за 1 день и при просрочке — рамка карточки и метка становятся красными
- **Приоритеты**: высокий / средний / низкий цветовой меткой
- **Поиск** по названию и описанию, **сводка по статусам** счётчиками по колонкам
- **Комментарии** к задачам, в том числе баг-репорты с отметкой

## Роли

| Роль | Видит | Может |
|---|---|---|
| PM (администратор) | все задачи, все колонки, всех пользователей | создавать, удалять, редактировать, назначать, двигать |
| Разработчик | свои задачи + бэклог без исполнителя | двигать свои задачи «В работе → На ревью», комментировать |
| Тестировщик | задачи в колонке «Тестирование» | «Тестирование → Готово» или возврат с баг-комментарием |
| Заказчик | только «Готово» и сводку по статусам | просмотр без редактирования |

Переключение пользователя — в меню справа в шапке (демо-режим без авторизации).

## Быстрый старт

Проект статический, сборка не нужна.

```bash
# вариант 1 — просто открыть
index.html

# вариант 2 — локальный сервер
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

```
index.html          — разметка страницы
styles.css          — стили по брендбуку (палитра, типографика, оттенки колонок)
app.js              — логика: роли, доска, переходы, уведомления, окна
docs/board.png      — скриншот для README
Тех_задание.txt     — ТЗ (функционал MVP)
Брендбук.txt        — ТЗ по визуалу и стилю
```

## Технологии

Чистые HTML, CSS и JavaScript без фреймворков и зависимостей. Шрифт Inter подключается с Google Fonts, при отсутствии сети подставляется системный шрифт.

## Хранение данных

Данные (задачи, уведомления, выбранный пользователь) хранятся в `localStorage` браузера. Чтобы вернуть исходное демо-состояние доски: меню пользователя → **«Сбросить демо-данные»**.

## Дизайн

Визуал сделан по брендбуку «Спокойный фокус»:

- Фон страницы `#F5F5F7`, карточки `#FFFFFF`, акцент — индиго `#4F46E5`
- Приоритеты: высокий `#EF4444`, средний `#F59E0B`, низкий `#10B981`
- Каждая колонка доски — со своим оттенком, чтобы темы читались визуально
- Карточки: скругление 12px, мягкая тень, подъём при наведении
- Иконки тонкие линейные (stroke 1.5px), без градиентов

## Публикация на GitHub Pages

Репозиторий статический, поэтому Pages работает «из коробки»: Settings → Pages → Source → `main` / корень. Никакая сборка не требуется.
